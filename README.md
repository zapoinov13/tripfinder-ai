# Voyage Finder

ТЗ — ВИЗУАЛЬНАЯ СТРУКТУРА TRAVEL MARKETPLACE

Создай современный premium travel marketplace для поиска и подбора туристических туров от разных туроператоров

Главная задача этапа — создать полноценный визуальный интерфейс, структуру страниц, навигацию и UX-потоки с demo-данными.

1. Общий стиль

Стиль:

современный travel-tech;

premium;

минималистичный;

clean UI;

много воздуха;

большие фотографии путешествий;

аккуратные карточки;

мягкие скругления;

лёгкие тени;

современная типографика;

визуально дорогой продукт;

интерфейс должен напоминать современный marketplace / SaaS, но не копировать конкретные сервисы.

Основной акцент — фотографии путешествий и удобство поиска.

Цветовая система:

светлый основной фон;

белые карточки;

тёмный текст;

один яркий accent color для CTA и активных элементов;

небольшое количество декоративных градиентов.

Не перегружать интерфейс цветами.

29. ВАЖНО

На этом этапе НЕ реализовывать:

реальные API;

реальные платежи;

реальное бронирование;

настоящую AI-интеграцию;

сложную авторизацию;

production backend.

Использовать demo data и mock interactions.

Но архитектуру интерфейса сделать так, чтобы позже эти функции можно было подключить без переделки UI.

Главная цель текущего этапа:

Собрать визуально цельный, дорогой и современный prototype полноценного travel marketplace.

Сначала реализуй HOME PAGE + SEARCH RESULTS + TOUR DETAILS + OPERATOR LANDING + OPERATOR DASHBOARD + ADMIN DASHBOARD.

После этого проверь desktop и mobile версии и только затем переходи к остальным страницам.
