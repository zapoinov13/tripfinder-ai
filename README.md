# TourGo

TourGo — travel marketplace для русскоязычных туристов из стран СНГ. Платформа рассчитана на разные страны и типы поставщиков, но первый живой каталог запускается по Дубаю.

## Что уже собрано

- Туристический поиск по предложениям: пакетные туры, отели, экскурсии и трансферы.
- AI-подбор по свободному описанию поездки.
- Dubai-only стартовый каталог: JBR, Dubai Marina, Palm Jumeirah, Downtown, семейный отдых, бюджетные районы, сафари, яхты и city tickets.
- Карточки предложений с рейтингом, питанием, ценой, Hot Deal/Premium/Sponsored бейджами.
- Личный кабинет туриста: избранное, сравнение, бронирования, price alerts.
- Кабинет поставщика: каталог, заявки, API/CSV-синхронизация, продвижение, биллинг.
- Админка платформы: модерация предложений, поставщики, платежи, Premium, аудит, настройки.
- Supabase seed для стартового Dubai-каталога.

## Продуктовая логика

TourGo не должен быть “сайтом только про Дубай”. Бренд и навигация остаются общими, чтобы позже подключить новые страны. При этом все доступные предложения на текущем этапе относятся к Дубаю, и визуальные материалы каталога тоже должны быть дубайскими.

## Локальный запуск

```bash
npm install
npm run dev -- --host 127.0.0.1
```

Локальный адрес по умолчанию: `http://127.0.0.1:8080/`.

## Сборка

```bash
npm run build
```

## Supabase seed

```bash
node scripts/generate-supabase-catalog-seed.mjs
```

Команда перегенерирует `supabase/seed_catalog.sql` с Dubai-only стартовым каталогом.
