# Домен и поисковики

Что сделать, когда подключите официальный домен. По порядку, сверху вниз.

## 1. Домен в Vercel

Vercel → проект → **Settings → Domains** → добавить домен и прописать записи
у регистратора (Vercel показывает какие). Один домен назначить **основным**:
второй должен на него редиректить, иначе поисковик увидит два одинаковых
сайта. Обычно основной — без `www`.

## 2. Одна переменная окружения

Vercel → **Settings → Environment Variables**:

```
VITE_SITE_URL = https://ваш-домен
```

Без завершающего слэша, для Production. После этого **Redeploy**.

Что изменится: `canonical`, `og:url` и картинка превью станут абсолютными.
Пока переменной нет, сайт работает нормально — адреса просто остаются
относительными (`/about`), и это тоже корректно, но абсолютные надёжнее для
превью ссылок в мессенджерах и X.

Проверить после деплоя: открыть исходный код главной и найти
`<link rel="canonical" href="https://ваш-домен/">`.

## 3. Google Search Console

1. https://search.google.com/search-console → **Добавить ресурс** → домен.
2. Подтвердить владение (проще всего TXT-записью у регистратора).
3. **Sitemaps** → добавить `sitemap.xml` (полный адрес: `https://ваш-домен/sitemap.xml`).
4. Через сутки посмотреть **Страницы**: сколько проиндексировано и что
   исключено.

Карта сайта собирается сервером сама и включает все одобренные компании и
активные предложения. Ничего вручную обновлять не нужно.

## 4. Яндекс.Вебмастер

https://webmaster.yandex.ru → добавить сайт → подтвердить → **Индексирование →
Файлы Sitemap** → тот же адрес карты. Для Казахстана и СНГ это половина
трафика, не пропускайте.

## 5. Что уже сделано в коде

- У каждой публичной страницы свой заголовок, описание и `canonical`.
- Карточка компании и предложения отдаются сервером целиком: поисковик и
  человек по присланной ссылке видят содержимое сразу.
- Разметка Schema.org: организация и поиск по сайту, `TravelAgency` с адресом
  на карточке компании, `Product` с ценой на предложении, хлебные крошки,
  FAQ на странице «О сервисе».
- `robots.txt` и `sitemap.xml` отдаёт сервер с правильным доменом.
- Кабинеты (`/admin`, `/operator`, `/profile`, избранное, сравнение, вход)
  закрыты от индексации.
- Несуществующая компания или тур отвечают 404, а не пустой страницей.

## 6. Чего ждать по срокам

Индексация занимает от нескольких дней до пары недель. Первыми появляются
главная и разделы, затем карточки компаний. Ускорить можно только тем, что
у поисковика уже есть повод прийти: живые компании, реальные описания и
ссылки на сайт извне.

Что действительно двигает позиции дальше: заполненные карточки компаний
(описание, фото, услуги с ценами), отзывы и регулярно обновляемые
предложения. Пустая карточка не ранжируется, сколько её ни оптимизируй.
