# TourGo Supplier Feed

Единый JSON-формат, чтобы турфирма **не вела каталог в двух системах**: выгрузка у себя → TourGo синхронизирует карточки, заявки остаются в кабинете TourGo.

## Тарифы

| Тариф  | Каталог                                                 |
| ------ | ------------------------------------------------------- |
| Старт  | Вручную, ссылка на сайт, черновик из Telegram           |
| Бизнес | + Supplier Feed (URL / JSON)                            |
| Про    | + live перепроверка цены при заявке, приоритет в выдаче |

## Формат

См. пример: [`/public/supplier-feed.example.json`](./public/supplier-feed.example.json)

Обязательные поля тура: `external_id`, `title`, `hotel_name`, `price`.

`external_id` стабилен у вас. по нему TourGo обновляет карточку, а не создаёт дубликат.

## Подключение

1. Тариф «Бизнес» или «Про»
2. Кабинет → Туры → «Загрузить по API»
3. URL до JSON (или вставка JSON)
4. «Загрузить с URL» / «Импортировать JSON»

Серверный прокси (обход CORS): Edge Function `sync-supplier-feed`.

```bash
supabase functions deploy sync-supplier-feed --project-ref mgyufoyornzbwvgdfojb
```

## Telegram (черновик)

В «Добавить тур» → из Telegram: вставьте текст поста / ссылку `t.me/..` / описание с ценой и отелем. Система соберёт черновик; перед публикацией проверьте поля. Полноценный бот (авто-посты из канала). следующий этап на том же `TourDraft`.
