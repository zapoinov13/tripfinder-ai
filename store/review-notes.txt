TourGo — App Store / Google Play Review Notes
============================================

App type: Travel marketplace (Capacitor shell loading https://tripfinder-ai.vercel.app)

How to test:
1. Open the app — compact mobile UI with bottom tabs: Home, Search, Trips, Profile
2. Search tours on Home or Search tab
3. Submit a travel request via "Заявка" or /request
4. Sign in with test accounts below to see profile, trips, messages

Test accounts (email + password):
- Tourist:  tourist@test.tourgo.app  /  Test1234!
- Operator: operator@test.tourgo.app /  Test1234!

Notes:
- TourGo does NOT sell tours. Users compare offers and pay the travel agency directly.
- Account deletion: Profile → Settings → Delete account
- Privacy: https://tripfinder-ai.vercel.app/privacy
- Terms: https://tripfinder-ai.vercel.app/terms
- Support: https://tripfinder-ai.vercel.app/support

Apple Sign-In: available on iOS login screen when Supabase Apple OAuth is configured.
Push notifications: optional; not required for core functionality.

If login fails on review build, use Browse as guest: search, destinations, hot tours, and request form work without login.

Russian UI — primary market Kazakhstan / Russian-speaking travelers.
